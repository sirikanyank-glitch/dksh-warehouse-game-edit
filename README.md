# ภารกิจคลังสินค้า 3D (DKSH)

เกมแข่งงานคลังสินค้า 3D เล่นพร้อมกัน 1–4 คนบนเครื่องเดียว ใช้ได้ทั้งเมาส์ นิ้ว (iPad) และจอยเกม USB
เขียนด้วย TypeScript + [Three.js](https://threejs.org) และ build ด้วย [Vite](https://vite.dev)

## เริ่มใช้งาน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 20 ขึ้นไป

```bash
npm install      # ติดตั้งครั้งแรกครั้งเดียว
npm run dev      # โหมดพัฒนา เปิด http://localhost:3000 (แก้โค้ดแล้วหน้าเว็บรีเฟรชเอง)
npm test         # รันชุดทดสอบกติกาเกม
npm run build    # สร้างไฟล์เผยแพร่ในโฟลเดอร์ dist/
npm run preview  # เปิดดูไฟล์ใน dist/ ก่อนนำขึ้นเว็บ
```

นำโฟลเดอร์ `dist/` ไปวางบนเว็บโฮสต์แบบไฟล์ธรรมดาได้ทุกที่ เช่น Netlify, Vercel, GitHub Pages หรือเซิร์ฟเวอร์ของบริษัท
**ข้อควรรู้:** ดับเบิลคลิกเปิด `index.html` ตรง ๆ จะไม่ทำงาน เพราะเบราว์เซอร์ไม่ยอมให้โหลดโมเดลจากไฟล์ในเครื่อง ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เช่น `npm run preview` หรือ `npx serve dist`

## โครงสร้างไฟล์

| ไฟล์/โฟลเดอร์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเมนู ปุ่ม HUD และข้อความวิธีเล่น (ภาษาไทย) |
| `src/main.ts` | จุดเริ่มเกม เมนู การตั้งค่า แถบสถานะ แป้นบังคับบนจอ และหน้าสรุปผล |
| `src/game/sim.ts` | **กติกาเกมทั้งหมด**: 5 ขั้นตอน การหยิบ/วาง การชนแร็ค โทษ และอันดับ |
| `src/game/config.ts` | **ค่าที่ปรับบ่อย**: ความเร็วเดิน/รถ ความเร็วหันตัว ความไวการชน มุมกล้อง |
| `src/game/layout.ts` | ตำแหน่งในคลัง สีผู้เล่น จำนวนกล่องต่อพาเลท และโทษชนแร็ค |
| `src/game/world.ts` | ฉากคลังสินค้า: พื้น ผนัง ป้าย DKSH แร็ค รถบรรทุก ตู้ และแสง |
| `src/game/actors.ts` | คนงาน รถลาก โฟล์คลิฟต์ แอนิเมชันเดิน และโลโก้บนเสื้อ/หมวก |
| `src/game/models.ts` | รายชื่อไฟล์โมเดล 3D ที่เกมโหลด |
| `src/game/game.ts` | เชื่อมทุกส่วน กล้องแบ่งจอ ข้อความพูด และเอฟเฟกต์ |
| `src/game/controls.ts` | รับเมาส์ ทัชสกรีน คีย์บอร์ด และจอยเกม (ผูกจอยกับสีตามลำดับการกดปุ่ม) |
| `src/engine/` | ระบบพื้นฐาน: ตัววาดภาพ ลูปเกม ตัวโหลดไฟล์ และเสียงประกอบ |
| `src/styles/`, `src/fonts/` | หน้าตา UI และฟอนต์ไทย Kanit/Mitr (สัญญาอนุญาต OFL ใช้ฟรี) |
| `public/models/` | โมเดล 3D (.glb) ของคนงาน รถ พาเลท กล่อง รถบรรทุก และตู้ |
| `assets/share/` | ภาพปกสำหรับแชร์ลิงก์ (og.png) และไอคอน |
| `tests/` | ชุดทดสอบกติกาเกมและลูปเกม |

## จุดที่น่าจะปรับบ่อย

- **ความเร็วเดิน รถลาก โฟล์คลิฟต์ และการหันตัว:** หมวด `move` ใน `src/game/config.ts`
- **โทษชนแร็ค (3 วินาที) และกล่องต่อพาเลท (4 กล่อง):** `PEN_BUMP` และ `BOX_PER` ใน `src/game/layout.ts`
- **ตัวเลือกจำนวนพาเลทและเวลา:** ปุ่มในหน้าเมนูของ `index.html`
- **ข้อความพูดขำ ๆ ของคนงาน:** `QUIPS` ใน `src/game/game.ts`
- **สีผู้เล่น:** `PLAYER_COLORS` ใน `src/game/layout.ts`
- **เปลี่ยนโมเดล:** วางไฟล์ .glb ใหม่ใน `public/models/` แล้วแก้ชื่อไฟล์ใน `src/game/models.ts`

## การควบคุม

- **คอมพิวเตอร์:** คลิกเมาส์ค้างที่แป้นสีของตัวเองใต้จอแล้วลาก คลิกปุ่ม "หยิบ/วาง" ข้างแป้น
- **iPad/มือถือ:** วางนิ้วที่แป้นสีของตัวเองแล้วลาก
- **จอยเกม USB:** เสียบจอยแล้วกดปุ่มใดก็ได้ในหน้าเมนู จอยที่กดก่อนได้สีแรกที่ยังว่าง โยกคันโยกเพื่อเดิน กดปุ่มใดก็ได้เพื่อหยิบ/วาง
- **คีย์บอร์ด (สำรอง):** P1 WASD + Space/F, P2 ลูกศร + Enter/Shift ขวา, P3 IJKL + U/O, P4 Numpad 8456 + 0/Enter
